# Innovativa SST Website

### Landing page B2B · simulador de preço · captação de leads

Experiência web responsiva para apresentar planos de SST e transformar tráfego em contatos comerciais qualificados.

## Recursos implementados

- Landing page responsiva;
- apresentação dos planos Super e Plus;
- simulador por quantidade de colaboradores;
- estimativa dinâmica de plano;
- máscara de CNPJ;
- formulário de lead com nome, e-mail e WhatsApp;
- consentimento explícito para contato;
- endpoint PHP para proposta;
- envio para cliente e equipe comercial;
- continuidade do contato via WhatsApp;
- FAQ interativo e navegação mobile;
- suporte a `prefers-reduced-motion`;
- configuração de implantação separada do frontend.

## Portfolio Edition

Telefones, WhatsApp e e-mails comerciais reais foram substituídos por valores demonstrativos ou placeholders.

Nenhuma senha SMTP, chave de API ou dado real de lead faz parte do repositório.
